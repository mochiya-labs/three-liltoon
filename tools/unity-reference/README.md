# Unity reference renderer

Use an approved Unity project with the pinned lilToon submodule commit to produce deterministic parity PNGs. The source scene must fix its mesh, textures, material properties, camera, light, render pipeline, color space, resolution, Unity version, and lilToon commit. Copy approved outputs into `test/parity/unity-reference/` and record per-fixture settings in `test/parity/scenes/`.

No Unity project or third-party avatar is committed here because the repository does not currently contain a redistribution-approved reference avatar. Never use an arbitrary downloaded VRChat/VRM asset as a fixture without its license.
